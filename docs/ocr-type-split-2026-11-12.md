# PDF 与图片转文字独立设置（2026-11-12）

本记录更新此前统一的文档识别设置。

- 模型详情分别提供「PDF 转文字」与「图片转文字」开关，以及各自的识别模型选择。
- 原 documentOcrEnabled / documentOcrProviderId / documentOcrModelId 保留为 PDF 配置。图片使用独立的 imageOcrEnabled / imageOcrProviderId / imageOcrModelId，默认关闭，不继承原统一开关。
- PDF 转文字只处理原 PDF 内容块。PDF 渲染产生的页面图像继续使用 PDF 识别模型，不受独立图片开关影响。
- 图片转文字只处理独立图片内容块（含旧版图片文件块），未开启的附件类型保持原输入形态。
- 同时发送 PDF 和图片时按类型分别选择模型，可来自不同供应商；仅解析本次实际用到的目标，未出现或未开启类型的失效目标不阻断其他类型。
- 两项配置都通过校验后才保存，取消或任一无效目标不会部分写入配置。
- 已有识别缓存继续按内容和目标模型复用。关闭某类型后不会因存在缓存而将该类型转成文字；新缓存附带 pdf / image 类型标记，工具记录分别为 pdf_ocr / image_ocr。
- 搜索、后台生成、取消和原附件持久化流程保留，不新增依赖或调整版本。
