# OChat 收尾记录（2026-11-02）

本文记录当日的实现与验证结果，不代表当前版本的完整测试状态。构建方法见 [README](../README.md#构建与测试)；下述 APK、报告和截图为本地生成产物，不随源码提交。

本轮对应此前审查的 1–10 项，以及主界面技术信息、HTML 预览说明、长会话性能三项。已保留青色主题、四分之三屏编辑和预览面板、思考强度滑动条及粒子效果。

| 项目 | 已完成的行为 | 使用入口 |
|---|---|---|
| 1. 发送前校验 | 在保存用户消息、清空输入和附件前检查地址、密钥、模型、参数和附件；配置失败会保留输入。 | 发送消息；弹窗可进入模型选择或配置。 |
| 2. 搜索恢复 | 搜索未配置时可以取消、配置搜索或关闭联网继续；Tavily 请求失败会明确标记本次未联网；内置搜索报错提供关闭联网重试。 | 输入栏联网开关；错误回复下的重试入口。 |
| 3. 供应商协议 | 增加 Anthropic Messages 和 Gemini 原生 REST 请求、鉴权、附件转换、流式解析及模型列表入口，保留 OpenAI 两种协议。 | 编辑供应商 → 接口协议。 |
| 4. 模型能力 | 思考档位按模型能力显示；不支持采样的模型不发送温度和 Top P；兼容网关可覆盖能力配置。 | 模型详情：采样支持、思考档位、上下文容量。 |
| 5. 结束状态 | 区分完成、达到输出上限、内容受限、未完成和连接中断；保留部分回复、结束原因与服务端用量；取消请求不再自动重发。 | 回复状态；长按消息 → 消息详情 / 继续回答。 |
| 6. 附件输入 | 修复总量重复计数，统一 UTF-8 / Base64 字节计数；SVG 以源码发送；旧 DOC/XLS/PPT 二进制格式明确拒绝并提示转换。 | 添加图片或文件；发送前提示。 |
| 7. 会话配置 | 模型、思考强度、系统提示词、采样参数、输出上限和联网开关随会话保存；旧会话尽量依据最后使用的模型迁移；凭据仍按供应商 ID 引用。 | 历史长按 → 对话设置；主页模型选择、思考强度。 |
| 8. 并行与队列 | 多个会话可独立生成和停止；生成时可切换会话；当前会话输入新内容后发送会加入队列，最多 10 条，按顺序发送。 | 正在生成时继续输入并发送；空输入时发送键用于停止；历史菜单可清空队列。 |
| 9. 上下文与用量 | 依据配置容量预留输出空间，按完整轮次省略早期上下文，保留系统指令和搜索材料；原始历史保留。记录实际返回的用量，并按选填单价估算费用。 | 模型详情设置容量和单价；回复提示；长按消息 / 对话查看详情。 |
| 10. 历史管理 | 置顶、归档、归档筛选、批量归档和删除；搜索显示命中片段并定位具体消息；ZIP 备份恢复包含历史、分支和可获取附件，导入时作为独立对话添加。 | 历史长按菜单；历史管理与备份。 |
| 11. 主界面信息 | 使用配置的模型显示名称；思考强度中文化；普通回复隐藏常驻的时间和模型 ID，技术详情移入长按菜单。 | 输入栏和消息长按菜单。 |
| 12. HTML 能力说明 | 代码按钮改为“静态预览”；面板明确不执行 JavaScript、交互功能不可用；增加首次载入提示并等待 WebView 实际绘制；保留图片、字体等远程资源加载。 | HTML / SVG 代码卡片 → 静态预览。 |
| 13. 长会话性能 | 消息以 40 条为一页翻看，搜索可跳到较早消息；历史列表复用条目，全文搜索在后台执行并防抖 250ms；缓存解析后的会话，后台串行保存，流式断点单独保存。保留代码视口状态并限制缓存大小。 | 查看更早 / 后续消息；历史搜索。 |

验证结果：Debug、Release 和 Android 测试 APK 构建成功；60 项 JVM 单元测试、37 项关键设备回归通过；Lint 为 0 errors、53 warnings。设备回归覆盖千条消息分页、输入保留、会话隔离、并行生成、后台恢复、附件与分支备份、请求取消、搜索以及代码双轴滚动。已目视核对主页、历史列表和完成绘制后的 HTML 面板截图。

新增原生协议通过请求结构、鉴权和模拟流事件验证，未使用真实供应商账号执行计费请求。上下文 token 是保守估算；服务端未返回用量时会明确说明，费用估算依赖用户配置的单价。首次载入仍需解析本地历史 JSON，本轮未进行真实设备帧率或内存峰值基准测量。

备份不包含供应商 API Key；单份对话 JSON 上限 32 MiB、单附件 20 MiB、附件总量 150 MiB，超限会报错。原文件失去授权时尽量使用保存的发送快照，无法取得的附件会标记缺失。HTML 和 SVG 以静态内容预览，脚本运行与本地文件访问保持关闭。

已核对的官方资料包括 [OpenAI 流式结束事件](https://developers.openai.com/api/reference/resources/responses/streaming-events)、[Claude Messages 协议](https://platform.claude.com/docs/en/api/http/messages)、[Claude 流式事件与用量](https://platform.claude.com/docs/en/build-with-claude/streaming) 以及 [Gemini REST 与思考配置](https://ai.google.dev/gemini-api/docs/generate-content/thinking)。
