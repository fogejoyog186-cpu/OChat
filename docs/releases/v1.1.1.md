# OChat v1.1.1｜轻量文档识别与内置工具

保持轻量、纯净，让文件内容确实进入对话。

- 撤掉 PDFBox 及其加密库依赖，PDF 转图使用系统组件。
- 按模型独立配置「PDF 转文字」与「图片转文字」，分别开启、分别选择视觉模型，再将对应识别结果交回原模型回答。旧版统一配置仅继承为 PDF 转文字，图片转文字默认关闭。
- PDF 逐页识别；按附件和识别模型缓存结果，避免后续对话重复调用。识别失败或输出不完整时明确停止。
- DeepSeek Flash 未开启识别时仍可直接接收 PDF 全部页面图像；Pro 等文本模型可通过文档识别读取扫描文档内容。
- 保留 PDF 原文件快照、流式编码、无本地固定 PDF 大小上限及预览翻页。
- 系统分享只将附件放入输入区，点击发送后才调用模型。
- 新对话沿用上次对话的模型；协议选择显示接口地址填写提示。
- 扩展 Anthropic、Gemini 的原生搜索、网页读取和代码执行，以及 Responses 代码执行和 Chat Completions 搜索专用模型支持。

文档识别默认关闭。开启后，附件会发送至指定识别服务并产生相应调用费用；不会发送整段对话。实际读取效果取决于识别模型，损坏、加密或未知二进制格式不会被当成成功识别。

版本：1.1.1；versionCode：3。
